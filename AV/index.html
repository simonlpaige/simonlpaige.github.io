Formula Reference
directEquipment = (baseCost x roomScale + featureCost) x complexityFactor x publicSignalFactor x rescueFactor x observedFactor
roomScale = 1 + (rooms - 1) x 0.6
featureCost = displays x 800 + mics x 450 + speakers x 350 + cameras x 1200 + dsp x 2200 + system_extras
complexityFactor = 1.0 + (complexity - 5) x 0.05
labor = directEquipment x laborPct
programming = directEquipment x programmingPct + extras
pm = subtotal x 0.075
contingency = subtotal x contingencyPct
subtotal = directEquipment + labor + programming + pm + contingency
sell = subtotal / (1 - margin)
Good = sell x 0.84 | Better = sell x 1.0 | Best = sell x 1.28
