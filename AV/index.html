Best Exports

  • Won or accepted proposal report with sell price, cost, margin, client, and date.
  • Client detail report so repeat-client behavior and account size can be weighted.
  • Line item or category report so display, audio, labor, control, network, and lighting patterns can be learned.
  • Project status report so stale, lost, and service-only opportunities do not pollute the winning-bid baseline.
  • Purchasing or cost report when available, especially for margin and vendor-risk calibration.
